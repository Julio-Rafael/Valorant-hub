Valorant Champions Hub

O Valorant Champions Hub é um site sobre o jogo VALORANT e o campeonato mundial VALORANT Champions Shanghai 2026, desenvolvido como projeto acadêmico para o curso de Análise e Desenvolvimento de Sistemas.

O projeto tem como objetivo aplicar os conhecimentos adquiridos nas aulas de HTML5, utilizando estrutura semântica, navegação entre páginas e diferentes elementos HTML.

O site aborda temas relacionados ao campeonato, como os times participantes, os agentes mais utilizados, as armas do jogo e os jogadores de cada equipe.

🎯 Objetivo

Desenvolver um site informativo utilizando HTML5 puro, colocando em prática os seguintes conhecimentos:

Estrutura básica do HTML5;
Tags semânticas;
Criação de páginas interligadas;
Tabelas com colspan e rowspan;
Formulários avançados;
Inserção de áudio e vídeo;
Utilização de imagens com figure e figcaption;
Elementos interativos com details e summary;
Marcação avançada de texto;
Organização de arquivos e pastas.
📄 Páginas
Início: apresenta o Valorant e o campeonato Champions 2026;
Times: mostra os 16 times classificados e os resultados;
Agentes: lista os agentes mais escolhidos no campeonato;
Armas: apresenta todas as armas do jogo e seus preços;
Jogadores: mostra os elencos das equipes e uma votação para o MVP.
